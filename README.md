# rock-paper-scissors-simple-game-
my first project -a simple rock paper scissor game
This is a simple Rock Paper Scissors game where the user plays against the computer.
## How to Play
Enter one of the following choices:
- `r` → Rock
- `p` → Paper
- `s` → Scissor
The computer randomly chooses one option, and the program compares your choice with the computer's choice.
result will be displayed
